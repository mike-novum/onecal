Структура папок и файлов в папке `./src` ведется по методологии FSD (feature-sliced-design). Подробные правила методологии можно узнать в навыке `/feature-sliced-design`


## Правила именования папок и файлов

### Папки

layer - kebab-case
slice - kebab-case
segment - kebab-case

Пример:

`src/pages/fast-food/ui/`


### Файлы

React-компоненты - PascalCase
Typescript типы и интерфейсы - PascalCase
Классы - PascalCase 
Функции - camelCase
Переменные - camelCase
Константы - UPPER_SNAKE_CASE


## Дополнительные правила для сегментов FSD

Связи между сегментами строить по следующим правилам:

- `ui` может использовать `model`, `api`, `lib`, `config`
- `model` может использовать `api`, `lib`, `config`
- `api` может использовать `lib`, `config`
- `lib` может использовать только `config` и внешние пакеты
- `config` не зависит ни от каких сегментов

## Группировка файлов в директории

Если React-компонент имеет помимо tsx-файла еще другие к нему относящиеся файлы (тесты, стили и т.п.) то такой компонент надо положить в свою директорию с таким же названием а внутри сделать index.ts.
