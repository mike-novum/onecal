---
name: audit-clean
description: >
  Используй, когда надо провести анализ и найти мертвый неиспользуемый код в проекте или указанных директориях
---

Для нахождения мертвого неиспользуемого кода следуй этой инструкции:

1. Проанализируй директорию на наличие мертвого кода, которую указал пользователь для анализа. Если пользователь не указал директорию в своем запросе, спроси у пользователя, не начинай аудит всей кодовой базы. 

2. Что можно отнести к мертвому коду:

- react-компоненты, функции, переменные, классы которые никак не используются (либо используются только в index.ts файлах, а снаружи никто их не использует);
- CSS-стили. которые нигде не используются;
- реэкспорт компонентов, которые могут использоваться внутри директории, но не использоваться снаружи (никто не импортирует этот компонент из этой index.ts точки);


3. Результат оформи в виде таблицы с колонками - №, Путь, Тип (компонент, функция, реэкспорт, переменная, класс), Назначение (краткое описание за что отвечает найденный элемент). Если у найденных мертвых элементов есть пометки в комментариях о том, почему их нельзя удалять, не добавляй их в свою таблицу.

4. Запроси подтверждение у пользователя, удаляй только если пользователь подтвердит твой отчет.
