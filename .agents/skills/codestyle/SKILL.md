# Валидация результатов

Запускай следующие скрипты, чтобы проверить код на очевидные ошибки:

`npm run tsc`
`npm run lint`

После крупных изменений запускай, сборку чтобы проверить что ничего не сломалось:

`npm run build`


# Комментарии

- не оставляй комментарии в коде, если я не просил
- не меняй и не удаляй комментарии в коде, если я не просил
