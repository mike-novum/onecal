PWA-приложение для трекинга вредных привычек и общего состояния. 

Данные хранятся локально на устройстве.

## Как пользоваться 
 
1. Открыть в браузере телефона ссылку https://mike-novum.github.io/
2. Сохранить на телефоне на главном экране

## Возможности

- экспорт/импорт данных
- трекинг употребления алкоголя
- трекинг употребления фастфуда
- трекинг принимаемых медикаментов

## Локальный запуск

```bash
npm install
npm run dev
```
