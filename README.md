# OneCal — календарь для всего подряд

Локальное веб-приложение-трекер: употребление алкоголя, курсы таблеток, фастфуд. Данные хранятся только в браузере (localStorage).

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, тесты: `npm test`.

## Возможности

- **Алкоголь** (`/alcohol`) — клик по дню открывает модалку с выбором напитков (эмодзи). В ячейке дня вместо числа показывается эмодзи напитка, при нескольких — 🎉, при включённом «было плохо на утро» — 🤮. Акцентная тема — синяя.
- **Таблетки** (`/pills`) — курсы с диапазоном дат и препаратами (название, дозировка, кратность, приём до/во время/после еды). Переключение «Список / Гантт» — горизонтальная диаграмма пересечений курсов. Акцентная тема — розовая.
- **Фастфуд** (`/fastfood`) — как алкоголь, со свитчем «болел живот». Акцентная тема — оранжевая.
- Экспорт/импорт всех данных в JSON (кнопки в шапке).

## Технологии

Vite + React + TypeScript, Tailwind CSS, zustand (persist), react-router, Vitest.
