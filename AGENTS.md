# О проекте

Это приложение-календарь для отметок своих вредных превычек и принимаемых медикаментов.

# Тестирование через браузер

Если тестируешь через браузер (playwrgiht-mcp) и делаешь скриншоты, не складывай их в корень проекта, удаляй их за собой либо складывай в `.playwrgiht-mcp` директорию.
